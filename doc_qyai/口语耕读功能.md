## 三、口语跟读对外 API（应用层可直接调用）

### 1. `qyai_mutilmodal_oral_reg_result_cb`

**函数原型**



```
void qyai_mutilmodal_oral_reg_result_cb(wbs_oral_result_callback cb);
```



**功能**

注册口语跟读打分结果回调。服务器返回打分结果 JSON 后，会通过这个回调把结果抛给应用层。

**参数**

| 参数 | 说明                                              |
| ---- | ------------------------------------------------- |
| `cb` | 打分结果回调函数，类型 `wbs_oral_result_callback` |

**回调执行线程**

回调在 **websocket 接收线程** 中执行。

**注意事项**

- 回调里 **不可阻塞**、**不可直接操作 UI**。
- 建议在回调里只做数据拷贝、置标志、发消息给 UI 线程等轻量操作。

**调用时机**

在开始口语跟读会话前注册一次即可。

### 2. `qyai_mutilmodal_oral_start`

**函数原型**

c

```
int qyai_mutilmodal_oral_start(uint8_t *text_in_buf, int text_in_len);
```



**功能**

开始一轮口语跟读打分会话。内部会完成：

1. 创建/复位 OS 对象；
2. 拼接 oral 服务器地址；
3. 建立 websocket 连接并握手；
4. 创建接收线程；
5. 上行跟读原文（TEXT）；
6. 状态切换到 `ORAL_STATE_UPLOAD`，之后可以推送录音 PCM。

**参数**

| 参数          | 说明                                                 |
| ------------- | ---------------------------------------------------- |
| `text_in_buf` | 跟读原文缓冲区                                       |
| `text_in_len` | 跟读原文长度，必须 `> 0` 且 `<= ORAL_PCM_CHUNK_SIZE` |

**返回值**

| 返回值 | 说明                                                         |
| ------ | ------------------------------------------------------------ |
| `0`    | 成功，会话已就绪，可以调用 `qyai_mutilmodal_oral_push_pcm()` |
| `-1`   | 参数错误（空指针、长度非法）                                 |
| `-2`   | 已有 oral 会话正在运行                                       |
| `-3`   | oral websocket 初始化失败                                    |
| `-4`   | 跟读原文发送失败                                             |
| `-5`   | 发送原文后检测到链路异常                                     |

**调用说明**

- 内部要建链 + 握手，是 **阻塞调用**，耗时可能百毫秒到数秒。
- **必须放在任务/线程里调用**，不要放在中断或对实时性要求很高的上下文。
- 返回 `0` 之后才能调用 `qyai_mutilmodal_oral_push_pcm()`。

### 3. `qyai_mutilmodal_oral_push_pcm`

**函数原型**

c

```
int qyai_mutilmodal_oral_push_pcm(uint8_t *pcm_in_buf, int pcm_in_len);
```



**功能**

推送麦克风采集的录音 PCM 数据到服务器。
内部会先把 PCM 攒到 `ORAL_PCM_CHUNK_SIZE`（约 100ms）再发，减少小包数量。

**参数**

| 参数         | 说明           |
| ------------ | -------------- |
| `pcm_in_buf` | PCM 数据缓冲区 |
| `pcm_in_len` | PCM 数据长度   |

**音频格式要求**

- 16K 采样率
- 16bit
- 单声道

**返回值**

| 返回值 | 说明                                                      |
| ------ | --------------------------------------------------------- |
| `0`    | 成功（包括服务器已判定说话结束、主动丢弃后续 PCM 的情况） |
| `<0`   | 失败（参数错误、会话未就绪、发送失败等）                  |

**调用说明**

- 采集线程按 20ms 一帧喂数据即可。
- 不等 ACK，避免阻塞采集线程导致丢音。
- 如果服务器已下发 `RESP_STATUS_SPEAK_END`，本函数会直接返回 `0`，不再上行。
- 只能在 `ORAL_STATE_UPLOAD` 状态下调用。

### 4. `qyai_mutilmodal_oral_finish`

**函数原型**

c

```
int qyai_mutilmodal_oral_finish(void);
```



**功能**

结束录音并等待打分结果。内部依次做 4 件事：

1. 发完攒着的残余 PCM；
2. 发空帧 EOF（`DATA_TYPE_PCM`，`data=NULL`，`len=0`），服务器收到后开始评测；
3. 等待服务器下发打分结果 JSON 和评语语音 PCM；
4. 关闭连接、释放缓冲区。

**返回值**

| 返回值 | 说明                           |
| ------ | ------------------------------ |
| `0`    | 成功拿到打分结果               |
| `-1`   | 当前没有 oral 会话             |
| `-3`   | 等待打分结果超时               |
| `-4`   | 会话过程中发生链路/服务器异常  |
| `-5`   | 服务器返回的业务 code 不是 200 |

**调用说明**

- 是 **阻塞调用**，最长等待约 20 秒（`ORAL_RESULT_TIME_OUT`）。
- **必须放在任务/线程里调用**。
- 无论会话过程是否异常，都要调用本接口收尾，否则连接和缓冲区不会释放。

### 5. `qyai_mutilmodal_oral_stop`

**函数原型**

c

```
void qyai_mutilmodal_oral_stop(void);
```



**功能**

中断本轮口语跟读会话（退出界面/异常时调用）。

**行为**

- 只置中断标记 `err_occurred = true`；
- 唤醒等待中的信号量 `result_sem`；
- **不直接释放资源**。

**调用说明**

- 真正的资源释放仍由 `qyai_mutilmodal_oral_finish()` 在发起会话的那个线程里完成。
- 避免跨线程重复释放。
- 如果当前 `ORAL_STATE_IDLE`，直接返回。

### 6. `qyai_mutilmodal_oral_is_upload`

**函数原型**

c

```
int qyai_mutilmodal_oral_is_upload(void);
```



**功能**

判断当前是否可以上行录音数据（采集线程判断用）。

**返回值**

| 返回值 | 说明     |
| ------ | -------- |
| 非 0   | 可以上行 |
| `0`    | 不可上行 |

**判断条件**

c

```
oral_info.state == ORAL_STATE_UPLOAD
    && !oral_info.err_occurred
    && !oral_info.server_speak_end
```

### 7. `qyai_mutilmodal_oral_is_running`

**函数原型**

c

```
int qyai_mutilmodal_oral_is_running(void);
```



**功能**

判断本轮口语跟读会话是否还在进行。

**返回值**

| 返回值 | 说明            |
| ------ | --------------- |
| 非 0   | 会话进行中      |
| `0`    | 会话已结束/空闲 |

**判断条件**

c

```
oral_info.state != ORAL_STATE_IDLE
```
